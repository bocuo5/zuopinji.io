# 阿成个人作品集

一个受现代实验型设计师作品集启发的纯静态个人网站。

## 文件
- `index.html`：页面结构与内容
- `styles.css`：全部视觉样式、响应式布局、动画
- `script.js`：滚动出现、鼠标跟随、平滑滚动

## 本地预览
直接双击 `index.html` 即可预览。

## 部署
可直接上传整个文件夹到：
- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

无需 Node.js、数据库或后端。

## 替换你的真实作品
当前作品区使用 CSS 生成的视觉占位图，因此网站开箱即用。
如果你要换成真实作品：
1. 把图片放入 `assets/`
2. 在 `index.html` 中把对应 `.project-image` 替换成 `<img src="assets/xxx.jpg" alt="作品名称">`
3. 修改作品标题、说明和联系方式。

## 建议下一步
把你的真实作品图、微信二维码、邮箱、社交账号和个人简介替换进去，就可以作为正式个人作品集使用。
